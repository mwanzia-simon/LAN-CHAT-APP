# LAN CHAT APP 

A beginner-friendly, terminal-based chat application built with Python and TCP sockets. This project demonstrates how computers communicate over a Local Area Network (LAN) using a client-server architecture.

##  Project Goals

- Understand client-server communication.
- Learn the basics of Python socket programming.
- Explore TCP connections, IP addresses, and port numbers.
- Build a chat application that can communicate across computers on the same network.

##  Technologies

- **Python 3**
- **Socket Programming**
- **TCP/IP Networking**
- **Command-Line Interface (CLI)**

##  Planned Features

- [ ] Create a TCP chat server.
- [ ] Build a client that connects to the server.
- [ ] Send and receive messages.
- [ ] Support multiple clients.

##  Getting Started

### Prerequisites

- Python 3 installed.
- A code editor such as Visual Studio Code.
- Two computers on the same local network for the LAN demonstration.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mwanzia-simon/LAN-CHAT-APP
   ```

2. Navigate into the project directory:

   ```bash
   cd LAN-CHAT-APP
   ```

3. Run the server and client using Python once their implementations are ready.

   ```bash
   python server.py
   ```

   ```bash
   python client.py
   ```

**Note:** The application is currently under development. The commands above are intended for use as the corresponding files are implemented.

##  Networking Concepts

| Concept | Description |
|---|---|
| Client | Initiates a connection to the server. |
| Server | Waits for incoming client connections. |
| IP Address | Identifies a device on an IP network. |
| Port | Identifies a communication endpoint on a device. |
| TCP | Provides reliable, ordered delivery of data. |
| Socket | Provides an interface for network communication. |
